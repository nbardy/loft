# How much of the Rust path can Loft delete?

**21,149 physical source lines today. The priced cuts leave 16,783, a reduction of 4,366 lines (20.6%).** The old loader supplies the largest saving, but it also contains the only working implementation of grid LOD in this area. The larger halving claim in the lean plan compares the old engine with its successor. Deleting the TypeScript compiler, host and WGSL lowerers is central to that result. Their source is outside this audit's denominator. The TS recorder and library remain clients throughout.

## One representation at each boundary

**4. Use the existing wire operator as the core table index.** `I/src/graph.rs:90-116,149-186` already owns ordered `Prim::ALL`, type checking and arity. **7. Lower draws directly from the graph into the final bundle tables.** The current path maps every draw, pass and medium into a core-local type, emits into private tables, then adds base offsets to names and module indices. Risk concentrates in three places. A mesh kernel ordinal is resolved through layout, a module can contain several named entries, and ground and outline can reference functions outside the draw's own module. Check a bundle containing all three with nonzero starting indices. Keep author/library origin and precision-alias choice in module equality. Compare full text on hash matches. **9, 15, 20 and 22. Classify once at the boundary that knows the answer.** For decoder bookkeeping, derive `PartialEq, Eq` on `Top` and use `Decls { program_roots: r0, ..Default::default() }`. The recorder numbers graph and raw functions together and the decoder renumbers graph-only references across draws, passes and media.
