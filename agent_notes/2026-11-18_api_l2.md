# Lane L2, conditions: one vocabulary for a condition over time (18 Nov 2026)

Design: `docs/proposals/2026-11-18_authoring_api.md` section 6, work plan row L2. Branch `feat/api-l2`, worktree
`~/git/_wt/loft-api-l2`, from main `83be87d`.

## What changed

- **`solve`'s holds are conditions** (`src/geom/solve.ts`). A hold is a boolean expression (`ge`, `le`, `gt`, `lt`,
  joined by `and`, or `equal`) for the whole span, or `always([time, a, b], condition)` for an interval, with
  `[time, t, t]` for an instant. Each is classified once (`holdsOf`) into a target band or a bound and its times. An
  `and` becomes two holds. `eventually`, `or`, `not`, `eq`/`ne` and an `always` over a param are refused by name:
  the search is local and cannot choose a time or a branch. The ranged check returned for a hold is the condition as
  written.
- **`equal(a, b, within = 1e-5)` returns a condition** (`le(max |a - b|, within)`). A registry that `equal` writes
  (a `WeakMap` keyed by the interned node) tells `solve` to pin it as a target. The same band written by hand is solved
  as the inequality it is. **Deleted:** `atLeast`, `When`, the `{ at }`/`{ from, to }` options of `equal`, and the
  timing code that went with them.
- **Sites.** `always`/`eventually` record their own line (`Ranged.site`), so a hold under `always` is named by its
  line. A bare hold is named by its place in the list: `ge over the whole span (hold 8 of the solve at
  examples/second/heron_leap.ts:97)`. A per-node stack capture in `ge` would cost too much; L1 text gives sites
  without one.
- **`clearance(body, target)` is a measure** (`src/check.ts`): an `Expr<"f32">` of time. For another body it is
  capsule to capsule (Ericson 5.1.9 with clamps and selects, guarded divisions). For a disc it is the footprint's
  distance in the water plane, and for a column the capped cylinder at the joints. These are the formulas the old
  sampled checks used, so the numbers agree with them (below). **Deleted:** `staysClear`, `stopsAt`. "Clear until
  arming" is `always([time, 0, T], ge(clearance(body, target), 0))`. "Stops at" is
  `always([time, T, T], le(clearance(part, target), contact))` plus `always([time, T - before, T + after],
  ge(..., -tol))`.
- **A skin target keeps its special case behind the same name.** The distance to a `skin` is a search over its mesh,
  not an expression. The design said to keep that special case, and the old ranged `skin` body only refused, so it
  could not stay as it was. `clearance(body, skin)` now returns a *measured leaf* (`measured` in `src/ranged.ts`): a
  variable of its own, registered with the CPU function that measures it at an instant. A condition that reads one
  must be a single range over time. `run` samples it at 60 Hz with both ends included and returns a **`sampled`**
  verdict. `decide` returns undecided with `spent: measured`, and `solve` refuses it as unreadable. The ranged `skin`
  body is gone.
- **Verdicts** (`Verdict` in `src/check.ts`). The `sampled` variant lost `holds`. It now carries `pass` and
  `samples`, the number of instants measured, which every library sampled check now reports; a custom check may
  leave it out. The table's verdict column reads `holds` / `FAIL` / `undecided` for a proof and `no failure at N
  samples` (or `no failure (sampled)`) / `FAIL` for samples. `checkOutcome` is unchanged (`pass`/`fail`/`undecided`).
- **Migrated:** `examples/second/heron_leap.ts`, `examples/strike.ts`, `examples/scenes/the_strike.ts`,
  `examples/second/{lighthouse,lantern,lanternfish}.ts`, `tests/{solve,ranged,spacetime,compute.gpu}.test.ts`,
  `tests/fixtures/mistakes/35_solve_conflict.ts`, and the guide's solve and checks sections. Also updated:
  `docs/errors.md`, `DESIGN.md` (checks paragraph and a new "one vocabulary" entry) and `docs/api.md` (regenerated).

## The user's code

```ts
hold: (c) => [
  always([time, 0, 0], equal(vec3(c.x, c.y, c.pitch), [0, HIP, 0])),   // stands
  always([time, 0.6, 1.2], equal(accel, [0, -G], 0.001)),               // flies: a parabola
  ge(c.fy, 0),                                                          // feet above the ground (bare: whole span)
  ...stations.map(([p, r]) => ge(length(sub(p.xy, rail)), r + pad)),    // clear of the rail
],

export const checks = [
  always([time, bite.first, bite.first], le(clearance(strikes.bite.part, ship), 0.1)),   // reaches it at arming
  always([time, 0, bite.first], ge(clearance(parts.body, ship), 0)),                     // clear until then
  budget({ triangles: 400_000 }),                                                        // sampled: says so
];
```

## What is left, and costs

- **Floor discontinuities defeat the proof.** The lantern's moth uses `dart`, whose clock of holds is a `floor`. A box
  that straddles the start of a hold encloses both holds' targets, and no split narrows it. The result is undecided
  with a lower bound of -0.44 on a box 2.8e-8 s wide, and `loft check examples/second/lantern.ts` exits 5. The
  example says why in a comment. The lighthouse hit the same thing at the repeating arming's cycle boundary (t = 0.3:
  lower bound -2.79 while the twin is 8.68). I moved its window to start at the motion,
  `[first - span.before, first]`, and said so. The fix belongs in `src/interval.ts` (not this lane's file): split on a
  floor that straddles an integer, the way the evaluator already splits on a select.
- **Cost of a proof over a heavy body.** In the_strike, the head against the hull's stand-in (a strand riding the swell)
  costs ~14 ms a box. At the default precision of 1e-4 the two head proofs take 148 s and 140 s; at 1e-3, 32 s and
  15 s. I set `precision: 1e-3` on those two, with a comment. The whole `loft check` on the_strike now takes 50 s;
  sampled, it took ~2 s. Near-parallel capsule pairs shrink their enclosures slowly: at a 1e-6 s box the width is
  still 4.5e-4 m, because the closest-point parameter divides by a determinant near 0.
- `litBy`, `minScreenSize`, `spansOnScreen` and `limbsReach` as measures (above).
- `cli/check.ts` (L7's file) still sums sampled checks under "N passed". With the verdict column changed, that line
  reads fine, but it could say "N held, M no failure in samples".
