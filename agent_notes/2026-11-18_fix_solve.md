# Solve lane, 18 November 2026

**D5 fixed.** Non-finite margins and derivatives used to disappear in comparisons. The CPU evaluator now checks
every evaluated root, including trial steps, verification samples and golden-section probes. Errors carry the
author's hold, source line and evaluation time. A local miss returns `unsolved` with starting-curve guidance.
An `infeasible` result requires a violated hold independent of the unknowns or disjoint bounds on the same
spline value or derivative at a shared time. Other affine conflicts can conservatively return `unsolved`.

One wall-clock deadline covers setup, optimisation, exchange, verification and conflict diagnosis. It is cooperative
at solver boundaries. A synchronous author callback or expression compilation must return control before a deadline
can be observed. Verified curves are cached by the interned graphs, families, preference, span and clearance target.
Mutable curve-row contents also enter the key. Hits report this call's time and work and retain the current source lines.

**D6 fixed.** Inequalities aim for `report.delta` (default 1e-6) and check the authored bound. Equality allows
±1e-5 per component. Each solved hold retains its margin and window and implements a ranged `always` check.
The heron design returns those checks.
