# Loft author compute, 18 Nov 2026

`compute(name, spec)` declares the entry point, workgroup counts, outputs and earlier outputs it reads. Put the returned
record in `scene({ compute: [...] })`. The compiler makes one dependency order per phase and emits the complete recipe
for both loaders. A GPU build writes raw buffer or packed texture blobs and drops the build kernels. The GPU-less
compile child hands the same recipe to the server. Load jobs and stepped histories finish before the loader returns.
The frames only read history. Each frame clears its own outputs and runs its author dispatches before replay and pose.

## The author's code

```ts
const wave = compute("wave", {
  when: { kind: "frame" },
  writes: { height: { kind: "texture", size: [64, 64], format: "r32float" } },
  entry: "fill",
  dispatch: [8, 8],
  wgsl: `
@compute @workgroup_size(8, 8) fn fill(@builtin(global_invocation_id) i: vec3<u32>) {
  textureStore(height, vec2<i32>(i.xy), vec4<f32>(sin(f32(i.x) * 0.18 + loft_time())));
}`,
});
const value = wave.height.sample(vec2(u, v)).x;
```

The [volume](../examples/compute_volume.ts) bakes a 48³ scalar SDF and traces it in a raw drawable.
The [particles](../examples/compute_steps.ts) step 2,048 grains at 60 Hz and keep one state in four. A raw drawable
reads position by time. The [pattern](../examples/compute_frame.ts) reads a load-time palette, writes a frame texture,
and uses an expression to sample it for paint. The latter's exported check reports `undecided: raw compute "pattern.colour"`.

## Measurements

Apple M4, Metal, 1280×720, front view. Rust load is one process's `Loft::load` time including pipeline setup, GPU
uploads and load jobs. Runtime GPU entries are medians from 20 `loft-view` frames, including the compute/pose and
draw spans. The frame clears precede that span. Dawn load is the median of three repeats on one warmed device, recorded
during shared GPU testing, and includes the one-shot kernels and step bake. Artefact bytes sum the manifest, WGSL and
blobs. The memory column is derived from declared compute resources and excludes rendering, staging and driver overhead.

| Example | Artefact bytes | Declared GPU bytes | Dawn warm load | Rust load | Rust GPU, median |
|---|---:|---:|---:|---:|---:|
| SDF volume | 456,406 | 442,368 | 10.0 ms | 45 ms | 3.261 ms/frame |
| Dust at 1.2 s | 24,470 | 2,162,688 | 28.0 ms | 197 ms | 0.491 ms/frame |
| Pattern at 0.7 s | 20,208 | 32,800 | 8.7 ms | 59 ms | 0.102 ms/frame |

The SDF build submits 1,728 groups of 64 invocations. It stores 110,592 f32 texels in 442,368 bytes. Dawn build,
including allocation, pipeline, execution and packed readback, took 130.2 ms initially and 11.7–22.1 ms on repeats
on the same device during this run. A separate CLI build reported 121.9 ms. The temporary padded readback is 589,824 B.

The dust dispatches the seed and 120 steps, for 247,808 invocations. Its 31 snapshots occupy 2,031,616 B and two
scratch buffers occupy 131,072 B. The frame computes 4,096 texels. Its output and zero-source textures use 16,384 B
each and the load palette uses 32 B. Dawn's 0.065536 ms timestamp tick did not resolve the pattern dispatch individually.
WebGPU treats each compute dispatch as its own usage scope, so an output texture can be sampled by a later dispatch
in the shared frame pass. [WebGPU usage scopes](https://www.w3.org/TR/webgpu/#usage-scope).

## Decisions and remaining limits

The file format is v4 for author compute, with v1–3 still read and written for the existing schedule variants.
There were no tracked artefact directories in this worktree. The on-disk version-1 through version-3 contracts stay
available for builds already made with those versions.

Keep `recur` as the expression construct. It shares the alternating dispatch schedule with raw `steps`. Its generated
kernel writes retained states directly and the expression path supports checkpoint replay and the CPU twin. Raw steps
snapshot the author's output and hold the nearest preceding kept state. Giving `recur` the raw author construct would
lose that information. A future internal unification should preserve the direct writes and replay.

Buffer bindings currently use vec4 lanes and textures use the four portable floating-point or normalized formats
listed in the guide. The author must make load and step shaders deterministic and avoid data races. The Rust loader
takes finished build files, while the Bun GPU server owns the deferred-build path. GPU verification was on Metal.
