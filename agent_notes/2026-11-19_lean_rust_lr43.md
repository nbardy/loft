## What changed

- **One entry.** `package.json` exports only `"."`. The six layer files stay as `loft api`'s grouping, not as
  import paths. Every name of every layer resolves to the same declaration as the entry's (checked by
  `exportsOf` on all six: 0 differences), so `tools/migrate.ts` now maps `loft/<layer>` and archived
  `…/src/<layer>.ts` to `loft`. `docs/MIGRATION.md` says so.
- **Deduplicated barrels.** `src/spacetime/index.ts` repeated `src/actions.ts` and was re-exported by the entry as
  well. It is deleted. `hitContour`, `hitInradius` and `Contour`, which only it exported, are in `actions.ts`, so they
  now appear in `docs/api.md` (regenerated). Its 9 importers and the 4 that imported `styles.ts` or `checks.ts` by path
  import `src/index.ts` (13 files; the duplicate import lines are merged).
- **TS error classes mapped to `Error`.** Every refusal that is the scene's fault is now a `SceneError` (exit 4,
  Rust `Error::Scene`). `SceneError` takes either its four parts or a whole message. `RoutineError`, `StruckError`,
  `RestlessError`, `ExpressionError`, `PendulumError`, `BendError`, `GroundError`, `FieldScheduleError`,
  `FieldSafetyError`, `TableBudgetError` and `NotDataError` extend it. `verdict.ts` loses `isLibraryRefusal`, which
  dynamically imported the whole library to run an `instanceof` list. `isTypedRefusal` is synchronous. `serve.ts`
  loses its `NotDataError` special case. The full map:

  | TS class | Rust `Error` | Exit |
  |---|---|---:|
  | `SceneError` and its subclasses (`TextError`, `PbrError`, `SolveError`, `RangeRefusal`, `ShaderTextError` and the 11 above) | `Scene` | 4 |
  | `DesignError` (by `kind`: syntax and unknown names / numbers and conflicts) | `Usage` / `Scene` | 2 / 4 |
  | `UsageError`, `ApiError` | `Usage` | 2 |
  | `LoadError` | `Load` | 3 |
  | `EnvironmentError` | `Environment` | 6 |
  | serve's `Budget` | `Budget` | 7 |
  | `NativeError` | already the Rust `Error`, by its `kind` | its code |
  | `DerivativeError` (deliberately: a missing rule is Loft's gap) | `Internal` | 1 |
  | `ChecksFailed` | a check verdict, not an `Error` | 5 |
  | `TokenError`, `ParseError`, `Unbounded`, `BudgetStop`, `RawComputeError`, `ChildVerdict` | internal control flow; each is caught and re-raised as a row above | — |

- **Unreferenced exports in new code: 0.** `src/record/*` and `src/core/native.ts` had 6 exports with no reference
  outside their own file. 5 are no longer exported (`FnBody`, `WIRE`, `DeclRec`, `Report`, `Native`).
  `scoreModule` stays, because `score.ts` writes an entry that imports it by name.
- **`docs/bundle.md`**: the `scene.loft` V1 format as `loft-ir/src/bundle.rs` and `identity.rs` implement it, covering
  the layout, the JSON fields, the precision alias, the identity and the load refusals.
