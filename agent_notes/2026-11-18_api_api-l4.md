## What changed

- **Where author text sits.** `src/authored.ts` (new, leaf): a registry of WGSL the author wrote that the compiler
  places verbatim. `src/text/index.ts` registers each raw function's library text with its first line. `lower`
  (`src/host/lower.ts`) finds registered texts in each chunk and writes `Manifest.authored` (chunk name to
  `AuthorLines[]`, type in `src/artefact.ts`); absent when a scene has no raw text, so other artefacts are unchanged.
  `src/host/files.ts` refuses a malformed field (LoadError).
- **Refusals classified by line.** `src/host/host.ts`: a Tint refusal's first `:line:col error:` is mapped through the
  module's chunks to `Manifest.authored`. An author line is `ShaderTextError` (a SceneError whose site is the
  author's line: exit 4, not retried); any other line stays `EnvironmentError` (exit 6, retried). `src/cli/verdict.ts`
  takes the site from the error, since its stack is all Loft's.
- **Sites on statements.** `src/expr.ts`: `noteStatements(note)` ends each emitted statement with a block comment
  (`/* x.ts:12 flight */`; block, because `src/compile/compute.ts` joins statements onto one line). `rebuild` now
  records the node each rewritten node came from (`rewrittenFrom`): without it, `fold` and the frame-uniform hoist
  (`replace`) made new, unsited nodes, and the dust volume's `p - core` line lost its site (found by the check).
- **`loft show <scene> [--thing name] [--variant v]`** (`src/cli/show.ts`, new): an index of modules, or the modules
  naming a thing in full, chunk banners saying who wrote each, statement sites, and `// file:line` on raw lines.
- Fixtures: `tests/fixtures/show/dust_burst.ts` (section 3's dust burst in text plus a raw u32 hash),
  `tests/fixtures/mistakes/36_raw_wgsl_typo.ts`. Test: `tests/show.gpu.test.ts` (three checks, each naming its bug).
- Docs: `docs/errors.md` (refusal 36, a likely-refusal row, exit 6 wording), `docs/guide.md` (raw lines, `loft show`),
  `docs/artefact_format.md` (`authored`), `DESIGN.md` 2.7 "Generated code made visible". `docs/api.md` regenerated:
  unchanged (no public name added).

## Where I went off the design, and why

- The prelude is printed whole, not as declarations: the design's own check is that the text compiles as one module.
- No `--stage`: a draw's vertex and fragment entries are one module; pose and compute modules match `--thing` by label.
- No separate `origin` field per chunk: "has author lines" is the origin, and a line map classifies more finely than a
  chunk flag (a draw's chunk is mostly generated code around one raw function).
- Null adapter: bun-webgpu 0.1.7 opens Dawn's Null backend with `requestAdapter({ backendType: "Null" })` (lowercase
  `"null"` fails the struct pack and returns no adapter), and its `createShaderModule` runs Tint. Not wired into serve's
  confined compile child (serve.ts and its confinement are not this lane's); load-time mapping covers the check.

## What is left

  and the standalone `import.meta.main` entry of `show.ts` is gone.)

- `show` prints the f32 build; mixed modules are mapped for errors (the search runs per chunk) but not shown.
- Call-form statements have no sites (`--sites` stack capture is L7's).
- `Manifest.authored` holds file paths, so the identity's program hash of a scene with raw text depends on its path
  (never a false equality).
