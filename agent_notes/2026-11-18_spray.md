# Spray lane: `draw.specks`, 18 November 2026

Review note: the implementer shipped a top-level `spray(name, { count, grain, stretch, veil })`. Per the owner's
decision (no dust-specific name; one generic primitive) the reviewer renamed it to `draw.specks(name, count, speck,
{ stretch?, veil? })` (`draw.points` is taken by per-point instancing). It never had burst options; the burst,
drag and fan bias were already the example's own `flight` code. Below, `spray`/grain wording describes the same thing.

[100,000 grains](2026-11-18_spray/100k.webp) · [1,000,000 grains](2026-11-18_spray/million.webp)

`examples/spray_burst.ts` builds a red-clay burst behind a cleated boot. The 12 Gaussian puffs sample the same
flight equation at spaced grain indices and at 78% speed. The equation adds drag, gravity and a fan bias. The lamp
behind the cloud lights the grains and puffs. The base and `million` variants vary only the count.

## Author code

```ts
const grains = draw.specks("grains", 100_000, (i, t) => {
  const q = flight(i, t);          // the example's own burst: fan bias, drag, gravity
  const h = hash22(vec2(i, 111));
  return {
    at: q.at,
    radius: mix(0.0019, 0.012, h.x),
    colour: mix(vec3(0.55, 0.18, 0.063), vec3(1, 0.56, 0.25), h.y),
    opacity: q.fade,
  };
}, { veil: cloud, stretch: 0.004 }); // veil: the draw.density drawable, listed earlier in things
```

Loft evaluates the expression graph directly in an instanced draw, with no particle buffer or per-grain uploads.
It inherits rain's hashed instance index and depth-tested camera-facing geometry. The subpixel footprint snaps
the **raster bounds** to four pixel edges while the tent moves continuously. Padding the larger raster bounds keeps
MSAA from applying a second coverage factor. Rain still uses its separate streak and swell-clipping law and the same
landing hash drives its splashes.

The veil shares `draw.density`'s coloured ray integral. If the cloud has already drawn `Lfront + Tfront * background`,
the grain's straight-alpha source is `Lfront + Tfront * grain`. Thus an opaque grain replaces only what lies behind
it, and a fading grain mixes these two pictures. The integral is evaluated to the grain centre. Large sprays share a
GPU pose grid within the cloud bounds. The grid allocates 32³ vec4s, exactly 512 KiB, per cached cloud at either
grain count. It uses eight reads per lookup. A secondary scene camera, a cloud with distance haze, a shader-only sky,
or a small spray uses the direct integral. The separate secondary-camera fragment entry avoids paying for the
integrator's private bins in the main fragment pipeline. Media with up to 16 blobs now fill the light and cluster
tables with GPU maps, so the burst can build to files with zero CPU tables.

## Measurements

Apple M4, macOS Metal, Bun/Dawn, 1280×720 at 0.65 s, `game` camera. GPU timestamps from `loft profile --frames 18`.
The normal frame is the minimum of 18 and the grain attribution is the best block mean with pass overhead removed.
The measurements come from separate timing modes. The two counts submit 200,000 and 2,000,000 grain triangles,
respectively. The raster footprint of a subpixel speck covers four pixels before shading.

Before separating the two fragment entry points, an isolated 1M-grain probe measured 115.47 ms for the combined
shader, 36.77 ms for the cache alone and 27.72 ms when the grain shader ignored the veil. The scene, draw count and
pose tables were the same in that probe. That identified fragment pipeline cost above the cache lookup itself.

The GPU properties exercise a moving 0.6-pixel-radius speck, whose total red-channel energy stays within five 8-bit
levels across a pixel of translation. They compare front, inside and rear contrasts against acceptance ranges of
0.38–0.52 and 0.15–0.25 of the front value, require the rear black grain to preserve the cloud's radiance within four
levels, and verify an opaque body hides a grain. The direct and cached contrasts agree within five levels. The test
also loads a pass with an opposite camera and checks that its pipeline uses the direct fragment entry.

## Verification and limits

`pnpm typecheck`, both example variants with `loft check`, both `loft build` outputs, and the spray and Gaussian
GPU tests passed. A four-sample WebP still rendered byte-identically from the scene and from its built files.
The files loader reported zero compiler modules, and the loader-closure check passed. Eight focused tests across
spray, Gaussian integration, soft rendering and the storm cloud passed. The full suite's all-examples pipeline
case reached its 180-second timeout. The full-suite process later ended with SIGTERM (exit 143) before a final count.
An isolated retry with a 600-second test limit reached the 23rd example (`fleet.ts`) before its process also ended
with SIGTERM. Both invocations ended before reporting a complete result for the all-examples case.
A separate workspace edit added a test lock in `tests/setup.ts` after these invocations started.

Grains blend in instance order and write no depth. The grid smooths changes smaller than a cell, and grain
shading and attenuation are sampled at the centre of a streak. The million-grain burst exceeds 16.7 ms on this
adapter. More speed would require reducing vertex or blend work in high-overlap regions.
