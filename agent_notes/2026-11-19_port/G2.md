# G2 · CPU evaluation and differentiation

The gate target is 295/295 entries with zero byte differences in `probe.eval`.
For a job with M roots and N roots accepted by the probe, predict N value rows
in watch order, each with one 16-digit f64 word per numeric component or one
boolean spelling. No accepted roots produces exactly `closed 0\n`.
The compiled operation list visits each reachable DAG node once per scope,
plus each dependent loop body once per iteration. Each emitted scalar local
takes one slot. Compile-time identities use known operands only. In particular,
a dynamic NaN multiplied by a literal zero produces +0, while a dynamic zero
multiplied by a dynamic NaN produces NaN. A loop swaps its next values
simultaneously and tests its stop after that assignment.
