# P0 · Canonical WGSL names

Each `emitWgsl` starts both counters at zero. Write expression lets as `${prefix}${k}` in emission order, including
inside nested loops. The loop's `${L}n${j}` lets also advance `k` because they are written declarations. Open loops as
`${prefix}L${j}` in emission order, with the existing state, index and next suffixes. Nodes named by `pre` use those
names without advancing either counter.

Predict 295/295 shift entries with zero differing sections and 9/9 proof frames matching the pre-change pixels.
The change adds two integer counters per emission, with the same traversal and WGSL operations. The bead baseline
failed 13/63 sections. Its first difference was `probe.graph`, where `e412` became `e1412`.

## TypeScript changes

- `src/expr.ts` uses per-emission counters. A nested-loop check emitted identical text after creating 100 unrelated
  loops and preserved the incoming `pre` name. G1 can copy the counter rule above into its WGSL emitter.
- `src/compile/tables.ts` names map and scan binders from the table name, which is unique within the registry.
  These names reach the graph and wire probes. The executable WGSL binds them to its existing index and state names.
- The scan's init, hoisted and step emissions already use `a`, `h` and `e`. The two recurrence emissions, each map run,
  each raw compute accessor, each `bind.ts` function and each standalone text function have separate function scopes.
  `bind.ts` repeats `e` until its prefix avoids generated names that would shadow a function argument. With an
  argument `e0`, `mul(add(e0, 1), e0)` otherwise lowered to a multiply of the new local by itself.
- Rows reach WGSL as compile-local slots and the probes as labels or wire indices. The process-wide row ID is only
  an identity key. Standalone text library names follow the changed function-body hashes.

The compiler diff is 13 insertions and eight deletions. This lane translates zero Rust lines. `tools/port/ts_side.ts`
checks the selected export before entering the compiler and reports a typed load refusal for non-scene exports.
