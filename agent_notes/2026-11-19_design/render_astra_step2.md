# A renderer that can compile away a shadow ray

Render design, Step 2 · 19 November 2026 · source inspected at `2276005`

## What the consumer writes

**1. A polished bead on a matte floor.** The hole has one author. Changing its radius should change the silhouette, shadow, reflection and pick together.

```ts
import { scene, surface, difference, sphere, cylinderY, copper, matte, plane, look } from "loft"

const bead = difference(sphere(1), cylinderY(0.35))
export default scene({
  things: [surface(bead, copper()).at([0, 1, 0]), surface(plane(), matte(0.6))],
  sun: [-0.4, 0.8, 0.45],
  camera: look([2.5, 3.5, 3.5], [0, 1, 0])
})
```

The cylinder extends along local Y. Subtracting it from the sphere supplies a finite bound. The library's copper specifies a reflection law, the plane a neutral diffuse reflectance, and the default camera recipe a sky. These defaults live in source the consumer can import. A person who wants the hole to emit gold light can paint its cut face using the boundary identity returned by the difference.

**2. A primitive defined this morning.** This button is the intersection of a ball and a slab. It can go into the same scene as the bead. Its author supplies the mathematics, its domain and a material.

```ts
import { wgsl, field, surface, matte } from "loft"

const button = wgsl`
  fn button(p: vec3f) -> f32 {
    return max(length(p) - 1., abs(p.y) - 0.4);
  }`
export default surface(field(button.button, {
  min: [-1, -0.4, -1], max: [1, 0.4, 1]
}), matte([0.12, 0.32, 0.7]))
```

Each argument of the maximum is 1-Lipschitz, and taking their maximum preserves that bound. The compiler has enough information to take conservative steps and enough structure to recognize a sphere clipped by two planes. Replacing the body with a raw texture read still gives the author a GPU function. A safe step then needs information about the filtered texture. The diagnostic should point at that read and say which consumer needs the bound.

**3. Change one term in indirect as well as direct lighting.** A material researcher wants to compare the usual Smith visibility with a separable approximation. Roughness in this experiment is the perceptual roughness, and the function returns the visibility factor including the microfacet denominator. The view and light cosines are positive on this reflective lobe.

```ts
import { wgsl, pbr } from "loft"

const model = wgsl`
  fn visibility(nl: f32, nv: f32, rough: f32) -> f32 {
    let k = 0.5 * rough * rough;
    return 0.25 / (mix(nl, 1., k) * mix(nv, 1., k));
  }`
export default pbr({ visibility: model.visibility })
```

The edit changes path evaluation immediately. Any environment fit or multiple-scattering compensation that reads the old term becomes ineligible. The library can integrate the new term, or the consumer can use direct numerical evaluation while experimenting. A fit with a measured error has that error in its build record. At roughness zero the ideal smooth lobe is a discrete event handled by the outer material. This makes the domain of the editable formula intelligible.

**4. Choose a different light.** Here is an entire direct-light estimator for a nonempty set of point lights and a continuous reflective surface. A uniformly chosen light contributes the inverse of its selection probability. The library supplies unbiased bounded integer sampling and the offset and length for a segment to the chosen light. The light's incident intensity already includes inverse square falloff.

```ts
import { direct, wgsl } from "loft"

export default direct(wgsl`
  fn estimate(s: Surface, rng: Sample) -> vec3f {
    let n = point_count();
    if (n == 0u) { return vec3f(0.); }
    let l = point_at(rng_below(rng, n), s);
    return f32(n) * l.incident * bsdf_cos(s, l.wi) * transmittance(l.segment);
  }`.estimate)
```

The direct-light signature supplies five typed imports from the scene, sampler, material and medium. `bsdf_cos` multiplies the BSDF by the positive cosine between the shading normal and the sampled light direction. The public default scene accepts the resulting estimator as its direct-light function. A single light makes the selector constant. With 1,024 lights this version remains correct for its domain and gives the researcher an occasionally terrible, cheap-to-write baseline. An area emitter additionally needs a sample on its surface and a density in the stated measure.

**5. Replace the entire engine with a normal image.** A teaching application wants one linear image, dark grey wherever a ray finds empty space. It can run this program on scenes written for the beauty renderer.

```ts
import { image, wgsl } from "loft"

export default (world, view) => [
  image(view, wgsl`
    fn pixel(ray: Ray) -> vec4f {
      let h = ${world.first}(ray);
      if (!h.found) { return vec4f(0.08, 0.08, 0.08, 1.); }
      return vec4f(vec3f(0.5) + 0.5 * h.ng, 1.);
    }`.pixel)
]
```

`image` is the public fullscreen draw with a camera ray at the sample. It targets the view supplied by the caller. The function returns the complete ordered pass list. A consumer can replace that element with a raw compute dispatch into a storage texture, or submit hand-written draws on either side. Material evaluation, light sampling, tone mapping, history and their resources have zero callers here. A newly imported shape with only a raster shader would get a compile error at `world.first`, naming the shape that needs ray intersection.

**6. Draw inside a game.** This is the existing Rust embedding idiom with a forward-depth canvas. The game provides its device, queue, encoder, attachments, matrices and subject bytes. It owns submission.

```rust
let canvas = Canvas { color: format, depth: TextureFormat::Depth32Float, samples: 1 };
let mut bead = Loft::load(device, queue, bytes, Precision::F32, &[canvas], None).await?;
bead.set_camera(camera);
bead.encode_into(device, queue, encoder, &View {
    canvas, color, depth, size, owner: Owner::Caller, layers: Layers::Subject,
})?;
```

The first five excerpts specify the proposed public surface. The sixth is a call site inside a host that already imports the indicated Loft and wgpu types. Token counts in order are **124, 110, 95, 110, 113 and 91**. These are measured `o200k_base` tokens of each entire code block including imports, indentation and internal newlines, excluding fences and the trailing newline. The fourth pays for a real estimator. The fifth pays for everything specific to replacing the renderer. Each count includes all the application code specific to that change. [Current embedding contract](../../docs/keel.md)

## What gets to decide a pixel

In the existing high view of the bead, the warm ground shows through its central aperture. In the oblique view the bore reads as a dark red cut into the top of the sphere. Its black outline and soft shadow make both pictures legible. Keep those pictures as art targets. Step 1 found a ray from (0, 4, 0) straight down the centre for which the current public intersection returns a hit at distance 2. A pick can select copper where the artist drew empty space. We have both an image worth preserving and an equation worth correcting. Start with the observation someone wants. A pick asks which boundary is first along one segment. A pinhole camera asks for radiance, usually integrated over the area of a pixel. A point light asks how much light arrives along a segment. That request can collapse to one bit for empty space and opaque solids. A lacquer highlight needs the material frame and incoming light outside the camera frustum. A volume needs an integral through the space between boundaries. An outline can deposit ink where a geometric ray misses. The necessary work follows from the observation and the authored laws. Starting with a depth buffer gets this dependency backwards.

Give a shape an authoritative meaning in local coordinates. An imported triangle asset means its posed triangles with their declared winding, displacement, cutout rule and shading attributes. A difference means membership in A and outside B, with a reversed geometric normal on exposed B faces. A continuous field means its zero set and inside sign. A splat painting may mean individual oriented marks with filtered opacity. A voxel sculpture may mean fixed cells with an editable occupancy state. Each can offer several ways of answering a request. A triangle mesh cooked from a smooth equation becomes authoritative only when the author chooses that discrete geometry. Otherwise its deviation has to be accounted for at the observation that consumes it.

“Fastest exact” has a workable scope. Fix the law, request, spatial and temporal domain, sample convention and arithmetic. Admit equivalent schedules and certified approximations within the caller's stated tolerance. Rank the admitted schedules by measured whole-frame cost on the target. A proved identical rewrite can serve a strict request. A tolerance-based rewrite carries its bound, in units such as metres of hit distance. A sampled visual match earns an experimental candidate for that camera path. An approximate beauty recipe can explicitly choose a fitted shadow, diffusion model or denoiser. A fitted shadow then has a legitimate author and users can change it in one place. An exact first-hit request stays independently available. ## The small stable part

At execution the stable vocabulary is a typed resource, an entry point with a layout, and a pass that reads versions and writes versions. A render pass also describes its attachments, depth state and draws. A compute pass describes its dispatch. An ordered bundle of these runs on a supplied device. The encoder loads or clears according to attachment ownership, binds layouts, records work and returns to the caller. The steady-state interpreter should fit in a few hundred lines excluding wgpu initialization, validation, serialization, profiling and resource allocation. Count these other lines separately. A sun, an SDF opcode, a BRDF switch, a frame history heuristic or a game entity in the interpreter is evidence that a library rule slipped across the boundary.

The producer has more work. Reuse the typed graph in `loft-ir`. Functions have arguments, result, source span and declared resource effects. A function call in TypeScript records a use of a single body. A shader hole links to that same function or to a typed value. Loops remain loops. A raw WGSL function can be linked with validated types and explicit reads. The absence of a twin for its body is an observable loss of analysis. Preserve the raw code's author provenance through fusion so runtime validation uses the corresponding checks. The math graph, compiler and runtime form the meta engine. Intersection, light sampling, intersection acceleration, image formation and pass ordering live in replaceable libraries above it.

The following are semantic types, shown before packing. Their records need only exist where a caller reads them. They describe the wire extension and library signatures a Step 3 implementer has to reconcile with existing `Graph`, `Cover`, `Body`, `When`, `Target`, `Identity`, `Verdict` and `Error`. They need no separate class hierarchy.

| Value | Data and contract |
|---|---|
| Ray | World origin in metres, unit world direction, half-open distance interval [near, far), shutter time and sample footprint. A local affine transform preserves the world distance parameter when the transformed direction keeps its length. |
| Boundary | World distance, stable instance and primitive keys, local coordinates, geometric normal, incident side and material slot. The shading frame, UVs and previous position are derived on demand. `Miss \| Hit(boundary)` is the semantic result. |
| Solid | Primitive boundary/membership law, Boolean composition, transformed child or instanced children. CSG requires solids with meaningful interiors. An open triangle sheet can offer a surface hit and an explicit two-sided opacity law. |
| Medium | Supported region, spectral or linear RGB extinction and scattering in inverse metres, emission per metre and a phase law with its sampling distribution. An analytic integral or a valid majorant can accompany these functions. |
| Material | Emission and scattering at a boundary, with evaluation, sampling and density. Discrete probability masses and solid-angle densities are distinct variants. Boundary medium transitions follow the geometric orientation. |
| Request | First boundary along a ray, attenuation along a segment, or camera coverage over a footprint. Public render and light functions compose these results. Opaque occlusion is the binary reduction of attenuation under its premises. |
| Resource use | Element/texel type, extent, format, space, lifetime, access, input version and producer. Static bytes, closed functions of time, load products, frame products and stepped state reuse the existing rate and kernel machinery. |
| Pass | Render or compute over named uses, with explicit attachments or dispatch. Ordered versions define dependencies. A caller's attachment is imported with format, sample count, usage, extent, depth mapping and load/store contract. |

Integer identity survives sorting and batching. Reserve an explicit miss tag. A float lane carrying a copy index ceases to distinguish all neighbours beyond 2²⁴. Pack integers as integers, or use defined bit casts on a compatible storage path. The first slice can specialize the ID away where the target is only radiance. The tag and emitted integer lanes are an intentional extension of the present Rust role ABI that returns one `vec4` of normal and distance. Representing the tag as a compile-time variant or lowered branch is the emitter's decision. ## The invention worth trying

Compile **the particular question asked of a piece of geometry**. Inlining a distance function into several shaders still leaves each shader running the same traversal. Instead propagate which result components are needed and over what family of rays, then specialize the reduction itself. A solid described by intervals can provide the nearest exposed endpoint, just the existence of occupied length, or a medium interval over which extinction must be integrated. Express the implications as library functions with preconditions. A legal shortcut for one question can be completely useless for another at the same pixel.

The drilled bead gives an implementable derivation. For an exactly axial ray, horizontal squared radius q is constant. The sphere has occupied y interval [1−√(1−q), 1+√(1−q)] for q ≤ 1. The bore occupies the whole line if q < b². Subtract the intervals and clip to the segment. When the segment connects a receiver below the sphere to a light above it, binary occlusion reduces to two comparisons on q. The ray marcher, normal calculation, endpoints and square root disappear. A pick from the receiver still needs an endpoint and a hit ID. A minimum-width silhouette still needs a footprint. A glass bead keeps interface and path work. The same source geometry generates all four programs.

Now lift the two comparisons to a rectangular family of parallel rays. Compute the minimum squared radius by clamping the centre to the rectangle and the maximum at its farthest corner. If the whole rectangle is inside the hole or outside the sphere, every ray is clear. If it is strictly inside the outer disc and outside the bore, every ray is blocked. Otherwise keep the residual per-sample program. Equality stays mixed in this classifier. Record which interval comparison, material-opacity law, direction, transform and segment range justify the constant answer. A settled cell consumes one bit of visibility plus a tag for mixed. The first implementation can spend one aligned u32 per tile. This is a proof about every ray in the specified family, valid at a camera cut when those actual dependencies survive.

This lifting is an optimization of a public law. The bead author supplies the difference exactly once. In the library a cylinder supplies its radial inequality, a sphere its axial interval and a difference combines two occupied sets before the existential reduction. The compiler specializes known direction components and segment endpoints, discards dead outputs and tries interval bounds on the remaining predicate. With this order, the tile code falls out of common transformations. A recognizer matching a function called “bead” would fail the first time a stranger wrote the same definition with a different name. Require identical plans after alpha-renaming and putting the difference in a user function.

For general rays the interval solver accounts for a ray starting inside material, a ray parallel to and inside a bore, the empty interval and zero-width contact. A ray beginning inside an opaque solid can be blocked before it meets its first exit. Initial membership is therefore part of the interval reduction. Group coincident endpoints, apply membership changes together and let a stable primitive key break ties for shading. A tangency can be a geometric surface contact of zero occupied length. The surface and attenuation contracts explicitly choose the corresponding answer. At curved rims or grazing f32 predicates whose sign cannot be enclosed, retain the general computation with its declared precision policy. Adding a small number to the denominator manufactures roots on the very ray with which Step 1 caught the defect.

The harder application is coral. In each spatial node retain a residual of the author's actual CSG tree. Cull a child only when its interval cannot change a requested output throughout the node. For a hard minimum, a lower bound above a sibling's upper bound eliminates its value. Tied winners can still affect an ID. For a smooth minimum one needs the operator's support bound at that node. Preserve fold clipping and cell IDs. Expand the domain by the requested ink footprint where near misses contribute. Use instance-local coordinates to share residuals across rigid poses. Candidate schedules include proxy rasterization with analytic hit depth, cell traversal of the residual field and direct evaluation in a short leaf. The algorithm may keep different leaves for primary coverage and opaque rays. It can also share one traversal when the extra outputs are cheaper than a second structure. [Loft's tracing research, especially §§5.5–5.6](../../docs/tracing_sota.md)

The antecedents matter. Halide exposes algorithm and schedule separately. Slang specializes linked shader code. Dr.Jit traces user programs into kernels. Lipschitz pruning already produces locally equivalent CSG trees including smooth operators. Loft's own tracing research considers tile cones, part hulls and overlap lists. Claiming any of those mechanisms as the discovery would give the team the wrong engineering problem. The proposed addition is to derive a residual **per requested observation**, carry the premises through edited geometry, material and time, and allow that residual to compete with ordinary raster, analytic and traced implementations inside a caller's pass list. The specific research result would be a speed gain at matching depth, IDs, ink and light with fewer author definitions. That experiment establishes a result on the stated workloads. [Halide](https://halide-lang.org/) · [Slang linkage](https://shader-slang.org/slang/user-guide/link-time-specialization) · [Dr.Jit](https://drjit.readthedocs.io/en/latest/what.html) · [Lipschitz pruning](https://wbrbr.org/publications/LipschitzPruning/)

An accelerator author uses the same candidate interface as the library. A candidate is a function of the requested graph root, its domain and available resources. It can decline, or return a replacement subgraph, its applicability conditions and any setup passes. A recipe passes its list of these functions to the compiler. The returned subgraph uses ordinary graph operations and public kernel effects, so the compiler can validate it, price it, or print it. A consumer can supply a single candidate and inspect its result directly. This is how an independent team could replace the entire geometry planner while continuing to use Loft's materials, pass packing and host.

## How a composition reaches the GPU

1. **Record the program once.** The TS front end captures typed calls, loops, tables, source spans, public draw roles, resources, cameras and pass roots. Capture five transforms of a crab as five rows. Keep independent topology and stable keys for its articulated parts. Do structural hashing on function bodies with bound arguments renamed by position. A literal controlling topology can distinguish programs. An instance tint occupies a data lane. Make the distinction in the recorder so later passes never have to discover five equal bodies in a million lines of WGSL.
2. **Start at the outputs.** Trace colour, depth, ID, requested readbacks and resource effects backwards through the chosen pass list. Propagate rates and the required fields across calls. A shadow passing through a cutout leaf pulls in UVs, opacity, footprint and the sampler. Paint, roughness and normal maps have no influence unless the authored opacity actually reads them. A raw body is an optimization boundary for facts that cannot be inspected. Its declared reads still contribute to layout and invalidation. Preserve derivatives in fragment-uniform control flow or use an explicit gradient/LOD contract where divergent ray traversal enters texture code.
3. **Generate admissible candidates.** On a clipped quadric, try bounded analytic intersection first. For an imported indexed mesh, try raster for the eye and a tree over the same posed triangles for shadow or reflection. A swept or lathed vertex map can generate triangles directly when those triangles define the surface. A continuous silhouette needs a tessellation error bound or refinement against the equation. A field can march inside bounds with safe local steps and a termination/refinement policy. Exhausting a step budget is an unresolved query, observable in the build or execution diagnostics. Never classify that event as clear space in an exact schedule.
4. **Pay for the whole set of requests.** Building one BVH might slow primary-only drawing and speed a frame with two million secondary segments. Estimate the incremental build/refit, memory and per-query costs conditional on what is already live. Evaluate a small set of complete plans including all requested consumers. The first compiler needs only a greedy choice and a comparison with the simplest all-legal plan. On a target device, profile the finalists across a camera path and keep measured coefficients and plan choices under device, driver, resolution and workload keys. Reserve an offline tuning budget. A shipped scene loads its choice without timed experiments during a shot. Arriving on an unprofiled adapter selects a documented analytic cost estimate. Report that choice as predicted.
5. **Lower and pack.** Fold constants and common expressions, retain shared calls when inline expansion costs registers, and compare unrolling a small fixed loop with keeping it. Algebraic rewrites require the contracted precision, particularly under cancellation and at comparisons. Fuse consecutive pointwise image functions if their derivatives, colour spaces, neighbourhoods and side effects permit. Materialize a texture if a later consumer needs neighbours or another pass also reads it. Assign resources by format, usage and nonoverlapping lifetime. Keep history and borrowed attachments alive through their last use. Coalesce tables into the existing packs under the actual device limits. Emit per-kind kernels with runtime base/length/stride where putting those values in source would create another module for each population size.
6. **Expose the result.** Naga validates generated programs. A shader error maps through linked functions to the consumer's line, with the requesting pass and shape. Extend `loft show` to answer a concrete question such as “which law did the lamp use on the bead?” Print its specialized WGSL, accepted premises, resources, estimates and last matched timing. Generate the callable signatures for `loft context` from the same declarations that drove linkage. Hot reload builds and validates a candidate bundle, then publishes the resource versions and pipelines together at a frame boundary. A refused edit leaves a usable prior version with its own identity.

Cache identity has two levels of work, both derived from the existing identity scheme. Shader/pipeline keys include normalized code, layout, entries, precision, specialization and raster/attachment state. Keep object names and data values out unless a value is actually specialized. Baked data keys include source law, input bytes, domain, precision, filter, tolerance and generator version. Editing bead colour leaves an opaque shadow classification usable. Changing opacity, aperture, a transform relative to the lamp, or a ray endpoint bound revokes the corresponding premise. A rigid object-local tree survives a rigid translation. An acceleration structure over world bounds still needs refitting. An application may discard all cached data and obtain the same requested observations. Extend picture identity for the active recipe, asset digests, jitter seed, shutter and history lineage wherever those affect output. Record which schedule ran for reproduction. [Current identity](../../rust/crates/loft-ir/src/identity.rs) · [Rate analysis](../../rust/crates/loft-core/src/rate.rs) · [Pipeline cache](../../rust/crates/loft-gpu/src/cache.rs)

Portable execution uses raster, WGSL compute and bounded storage buffers. Budget against the negotiated device limits, including the baseline of four bind groups and eight storage buffers per stage for core WebGPU. Graph functions consume symbolic reads packed by the compiler. One stage layout serves all its linked functions. One packed software traversal admits leaf programs for triangles, interval solids and bounded fields. On native wgpu, an adapter with the required experimental ray-query features may traverse triangle instances and return procedural-box candidates to the same intersector. Test candidate support and bounds updates for that backend. For an assumed 0.8 ms refit and 4 ns saving per secondary ray, break-even is 200,000 rays per refit. At half a million rays the prospective net saving is 1.2 ms. A thousand-ray pick batch costs much less as a software query over an existing tree. Track both scratch peak and sustained allocation when making that choice. ## One world for light, participating media and marks

The library's reference recipe samples the camera, traverses the same geometry and integrates emitted and scattered radiance in linear units. It samples direct lights and scattering with multiple importance sampling where both proposals can reach a path. It accounts for event measures, medium transitions, transmittance, and the survival probability of Russian roulette. Use an unbiased termination scheme for convergence claims, record any finite-depth truncation as bias, and expose the random dimension used by every choice. Specular delta chains, total internal reflection and entering or leaving a dielectric need their own event branches. Keep geometric normals for sidedness and offsets. The shading frame and its correction belong to material evaluation. Closed functions of time and deforming geometry are sampled at the same shutter time all along a path. [PBRT's reference integrator](https://pbr-book.org/4ed/Light_Transport_I_Surface_Reflection/A_Better_Path_Tracer) · [Mitsuba's custom shape contract](https://mitsuba.readthedocs.io/en/latest/src/others/custom_shape.html)

An offline path tracer alone cannot arbitrate a bad common intersector. Keep independent known scenes. A white furnace tests directional or hemispherical energy within the chosen model. The rough unit-Fresnel single-scatter GGX control in Step 1 has normal-incidence albedo 1−ln 2 ≈ 0.30685. A compensating multiscatter conductor with no absorption in a uniform white environment should approach one. Turn an anisotropic tangent frame 90 degrees and inspect both highlight axes. Put a red emitter outside the frustum in the specular direction of a mirror. After disabling sky and all other emission the reflected red should persist across the camera cut. Add transmission, layered clearcoat, sheen, subsurface scattering and wavelength-dependent films as library laws with sampling and units. A thin film can use wavelength integration or an RGB fit with its documented illuminant and domain. It cannot recover arbitrary spectra from three unconstrained channel values. [Existing PBR parts and fit dependency](../../src/style/pbr_parts.ts) · [Filament material theory](https://google.github.io/filament/Filament.html)

For overlapping media use the transfer equation on each interval between relevant boundaries. Add the extinction coefficients of active media and add their local emission plus in-scattered source terms. For a homogeneous interval of length d the transfer is T = exp(−σₜd) and added radiance E = j(1−T)/σₜ, componentwise with the jd limit at zero extinction. Ordered *disjoint* intervals compose by (E₁ + T₁E₂, T₁T₂). For two coincident unit segments over black, red and blue, each with σₜ = ln 2 and source function one in its channel, predict linear RGB (0.375, 0, 0.375) and background transmittance 0.25. Reversing the declarations preserves both quantities. The old author-order composition gives 0.5 in one channel and 0.25 in the other. A single shared test now protects every surface, particle and shadow that uses that segment.

An analytic Gaussian can contribute an exact optical depth for a line integral over its specified support. Mixed coloured emission or varying incident light still requires source integration with total attenuation. A heterogeneous medium can use quadrature with a bound, or sampled free flights with a valid majorant and enough samples for the stated uncertainty. A point sprite representing emitted light and a grain acting as an opaque surface follow their own laws. Grains moving through fog read the same segment attenuation as the receiver behind them. A cached 32³ attenuation volume might amortize beautifully over 100,000 grains. The TS measurement was 1.56 ms for the grain draw with the grid against 120.8 ms marching per grain pixel, with separate pose work. Test thin densities moving across cells and charge updates before admitting that approximation into beauty. [Existing spray and media measurements](../../DESIGN.md)

The default real-time recipe begins with direct lighting and sky. The author can add light reservoirs, diffuse irradiance probes or denoising as explicit state and passes. A reservoir records proposal information and weight, surface/light identity, version and time needed by its reuse law. Revalidate visibility for the relevant segment. A moving opaque door can invalidate illumination at a perfectly stationary receiver. A probe records what integral it estimates, its spatial support and update age. A diffuse irradiance value cannot answer directional mirror radiance. On a cold 16-frame training clip compare first, fourth and sixteenth frames with a converged reference and charge preroll in full. Report linear patch bias, temporal flicker and display-space outcomes, with seeds and sampling uncertainty. Give the artist an unfiltered image to distinguish a bad lighting law from a bad denoiser.
