## MUST-FIX

1. **Authored edits cannot use Tier 0.** On the scored revision, `crates/loft-passes/src/tier0.rs::allocate` consumes manually supplied instructions. The compiler does not generate the tape for an edited E+ query. `Runner::register_tier0` has no production caller, and the native viewer uses its separate `Loaded` render path. The GPU proof exercises actual tape upload and native promotion on a constructed four-instruction distance field. There is no shaded-scene edit measurement through the public compiler. Motion must stay out of that interpreter. Browser promotion returns `Unsupported`; the change also lacks the requested full E101–E503 snapshot set. These require compiler and renderer implementations, beyond reconciling the lane interfaces. L23a is excluded.

2. **The runner fails two independent hard checks.** The core vocabulary scan returned zero matches in all four lanes. The production portability scan returned exit 1 on the native worker spawn and yield in `crates/loft-runner/src/tier0.rs`. Its debounce also uses a host clock. Wasm compilation passes because the worker is conditional. The combined runner has 2,951 physical source lines before its two directly included shared implementations add 778. Even discarding blank/comment lines, test files and everything after each file's first test-only section leaves 2,476 runner-local lines against 1,000. Restoring the limit requires moving the Naga CPU interpreter, edit scheduling and other policy out of the runner while keeping the frozen public backend. Hiding those implementations behind a source inclusion or changing the grep would leave the same violation. L23a and l23b are excluded.

3. **The required authored motion programs cannot compile.** The production CLI returned exit 1 and E405 for each of the spec's `body`, `state`, `solver` and `plan` declarations. The parser's `Item` enum has no cases for them. The normative grammar check accepts the checked-in corpus but cannot establish Rust lowering for an absent construct. There is no path from an authored `plan` to `loft_passes::plan::lower`, its Truth record or a scene's `sample_prior`. Typed kernel/solver scheduling and solver event lowering remain missing. L23b and l23c cannot supply the Phase 3 vertical slice through their existing interfaces. The pure numerical part of l23d is usable independently.

4. **The scene measurements exercise a reduced motion model.** In `scenes/heron.loft`, `HERON_CROUCH` sets the 0.59 m minimum directly. In `scenes/boss.loft`, the quintic call explicitly requests a 0.69 m windup. The 1,000-row test times the submitted scalar Scramble shader. It does not execute a full slice-indexed BODY/STATE/POSE solve with a 2,928-byte Boss state, surface-frame pinning, general support hulls or colored secondary constraints. The numeric values are valid observations of those scenes. They cannot establish that the missing solvers produce the poses. L23c is excluded.

5. **Asset texture validation has insufficient first-bind metadata.** The l23a implementation checks reflected view class, usage and shader-declared storage format, and compares subsequent handles with the first handle. Frozen `TableDecl` cannot express an asset's required resolution, exact sampled format, mip count and sample count. A shader-compatible first handle with the wrong resolution can therefore establish the wrong descriptor. The zero-copy gate below passes independently. Enforcing the asset contract needs a supplied descriptor at load/bind time. The freeze was preserved.

**Integration repairs on the scored revision.** The merged encoder retains both the edit pipeline and fused tick/outbox lifecycle. Native CPU stepping now reads the same current parameter bytes as GPU execution. Boss emits its two events at the authored transitions and the test no longer rewrites the scene in memory. The GPU acceptance checks every pixel in both Washer bounding squares. Profiling accepts serialized IR and runs the known shader in an actual GPU pass. The epoch test checks changed and unchanged groups across two passes with real external handle replacements.

## SHOULD-FIX

- The asynchronous pick callback in `loft-runner/src/pick.rs` converts a failed map into a miss with NaN depth. Synchronous picking translates it back into a typed failure. The asynchronous completion needs a distinct readback error so a consumer can distinguish failure from a background pixel.
- Motion bundle construction in `loft-passes/src/fusion.rs` gives each packed word a numeric name and discards the authored parameter's range. The source-reflection helper has only a test caller. Use source metadata in a production bundle while preserving the group-0 environment slots. The GPU parameter probe supplied its metadata explicitly.
- `loft-passes/src/plan.rs` converts LUT offsets with `expect`. The typed solver correctly returns `Unknown(SolveFailed)` on inconsistent or invalid problems. An unrepresentable LUT address should also reach its caller as a typed capacity refusal. Its 97 f32 playback samples use Hermite interpolation. The tighter f64 hold residuals measure the collocation solve.
