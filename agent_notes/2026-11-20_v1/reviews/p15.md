# Phase 1.5 review · E+ Parser Swap

**Hold the merge.** The E+ port reproduced the Phase 1 pictures and the Hermit token reduction. A valid map can put the compiler's culling box on the opposite side of its GPU geometry. The grammar fails to load in the target decoder, and the independent Load run held 25 of 33 checks.

Reviewed the unmerged `loft/v1-syntax` tip `4fd93bf` against merge base `fd66510`. The phase note scored implementation `ca21dbd`. Source locations below refer to the reviewed tip, except where marked **main**.

## MUST-FIX

1. **A Y rotation can cull the object it encloses.** `crates/loft-passes/src/eval.rs:439` uses the plane `(z,x)` while `crates/loft-passes/src/emit.rs:44` uses `(x,z)`. I compiled a radius-0.1 sphere centered at `turn.pt(0,0,1)` under `q |> rot_y(90deg)`. Its serialized instance bounds cover x = **[+0.874, +1.126]**. Its emitted shader puts the center at **−1**. Change the CPU Y plane to `(0,2)` to match WGSL, invalidate old derivations, and check the signed positions at ±90° against independent coordinates on both paths. Check that the derived box contains the drawn center and that map `.in` and `.out` invert each other.

2. **Pictures can lose a required frame and stay green.** `crates/loft-cli/src/gates.rs:422` silently drops malformed frame times. Line 162 then visits only the surviving times, even when the approved reference map contains more. Line 190 compares only the common pixel prefix, and lines 455 and 484 let an unknown scene filter return success with five 0/0 totals. A missing PNG for a *visited* frame does produce Unknown. Deserialize the manifest strictly, reject empty or duplicate selections and unknown scene names, require the exact approved scene/time keys for the selected cases, and require exactly `width × height × 4` bytes before comparison. Cover a deleted time, a malformed time, a short buffer and a misspelled selection.

3. **The normative grammar cannot load in llguidance.** `grammar/loft.lark:131` uses negative lookahead in `NUM_UNIT`. llguidance 1.9.1 rejects the grammar before the first token. Removing the lookahead in memory made it load. `tools/check_loft_grammar.py:11` exercises Python Earley only. Rust also rejects an `else if` expression which Lark accepts (`crates/loft-parse/src/parser.rs:1053`), and its schedule parser requires call syntax where the grammar accepts `waive Reason "…"` and `pass … reads […] writes […]` (line 318). Move the unit-boundary check into the lexer, use the decoder-supported grammar, parse block arms and the specified schedule forms, and run shared positive and negative examples through llguidance and Rust. Include all 14 existing files with the documented raw-island and newline handling.

4. **Load exceeded its caps, and the cold timer starts with a populated derivation cache.** `crates/loft-cli/src/gates.rs:456` compiles each scene before its timed cold compile at line 287. The nonce changes the pipeline key only. Line 69 starts timing after reading the sources. All six cold loads exceeded their caps on my run. Warm Hermit took **72.17 / 80.19 ms** at 1 / 20 instances against **60 ms**, although module, pipeline, shape and identity checks held. Start the timer before source loading, give each cold case a fresh derivation-cache directory and fresh pipeline key, and reuse both for its warm case. Report cache hits and front-end/device time separately. Obtain 33/33 on the corrected instrument or record an explicit Load ruling. The existing contention ruling covers Speed.

5. **An unproved divisor and an out-of-range row both compile.** `crates/loft-passes/src/refine.rs:51` loses module constants, line 94 discards the row dependency when either operand is unknown, and line 82 then skips E211. With `const offset = 1.0`, unrestricted `scale: f = 2` and `trace = sphere(…) / (scale - offset)`, the compiler certified L = 1 even though `scale = 1` is legal. Separately, `crates/loft-passes/src/eval.rs:388` and line 405 evaluate declaration defaults and endpoints in the caller's local scope. I emitted `scale: 0` into `scale: f > minimum` by shadowing the module's `minimum = 1` with local `−1`. Resolve declaration expressions in their defining scope after parameter overrides. Keep row dependency when interval information is unknown and require denominators to exclude zero before specializing a row. Keep explicit emit arguments in caller scope. Require E211 and E602 on these two cases and acceptance on a proven positive divisor.

6. **Twin can pass an out-of-contract difference or a NaN.** `crates/loft-cli/src/gates.rs:48` grows the allowance with magnitude, and line 234 applies it even to materials. At 100 it permits about `9.54e-5`. ABI §5 specifies absolute component limits of `1e-5` for fields, `1e-4` for AD normals and `2e-5` for lit materials. At line 241 an isolated NaN disappears in `min`/`max`. An empty comparison also retains positive-infinite slack. Apply the three absolute limits, require finite operands and a positive comparison count for each required quantity, and use the same evidence checks for Truth reductions at line 325. Exercise a value near 100, a one-sided NaN and zero samples. The observed claw material error was `1.115e-5`, within the specified material limit.

7. **Truth and the CLI can return green without executing a scheduled check.** `crates/loft-cli/src/gates.rs:321` scores geometric properties. `crates/loft-cli/src/main.rs:88` compiles the scene and returns success even for a scheduled `check always_misses(h: K) -> f { missed(1.0) }`. The snapshot encoding at `crates/loft-passes/src/emit.rs:478` handles only Held and Missed. For this phase's supported row-local subset, execute the scheduled checks for the requested ticks, require one result per expected check and row, decode all three Verdict variants, and surface missing/nonfinite evidence as Unknown. Preserve the existing 34 geometry checks and report authored checks separately. An always-missed check, an unknown verdict and an omitted result must each fail Truth and return exit 2.

8. **Continuous scene values change the code identity of a kind.** `crates/loft-passes/src/lib.rs:462` substitutes an override into the constant expression, which `crates/loft-passes/src/emit.rs:506` emits as WGSL. In the supplied Heron scene, changing only `--set side=1` to `--set side=-1` changes the Fish shader into a different module with a different literal. Line 469 of the emitter also specializes on whether the scene emitted environment rows. The 1-vs-20 module check misses both cases. Put query-visible continuous values and environment defaults in row or parameter storage, and keep their WGSL loads stable. Assert byte-identical modules across both fish positions and absent/present environment overrides while verifying that the resulting data changes the picture. The Phase 2 live host setter can land separately.

9. **The advertised reusable material helper fails during lowering.** `crates/loft-passes/src/emit.rs:535` recognizes only directly returned lobe sums. A valid `fn chitin(p,n) = ggx(…)` called from `material(q,n) = chitin(q,n)` produced E405. A helper declared inside its kind produced E011 when its trace called it (`crates/loft-passes/src/check.rs:884`, `crates/loft-passes/src/lib.rs:87`). Resolve kind-local and module calls once, instantiate the declared or inferred space at each call, and derive lobe layout through the resolved return expressions. Reuse that resolution in evaluation, emission and dependency collection. Compile a shared material in two distinct spaces and a trace that calls its kind-local helper.

10. **A build can read runtime time through a helper.** `crates/loft-passes/src/check.rs:884` checks the callee's build flag without propagating the runtime dependencies of ordinary helpers. `fn clock_now() -> f = time` compiled when used as an emit argument. The build thereby stored the evaluator's initial time. Propagate stage requirements through helper calls and constants, and issue E403 at the offending build use with the runtime read as a secondary span. Preserve build access to pure helpers. Check the transitive case alongside the direct read.

11. **A loop variable can silently become a row-field read.** `crates/loft-parse/src/parser.rs:878` parses the loop body before introducing the binder into its local scope. Line 1165 then rewrites the name to a member of `self`. Summing `f32(scale)` in `for scale in 0..2` with a row field `scale = 2` emitted two reads of `self_.r_scale`, yielding 4 instead of 1. Bind the range or list iterator for the body only, restore its previous binding on exit, and verify the sum on CPU and GPU with a same-named field.

## SHOULD-FIX

1. **The default renderer draws unused declarations and resists forking.** `crates/loft-passes/src/defaults.rs:34` selects every declared query kind before build. The recipe itself is assembled in Rust at `defaults.rs:136`, `lib.rs:586` demands one literal pass order, and `lib.rs:72` silently accepts `use fake::lighting::*`. Select populated kinds after build, expose the default recipe as forkable engine source, resolve imports or issue a spanned E011, and validate resource dependencies when elaborating an explicit schedule. Verify that an unused kind is harmless and a missing import is diagnosed.

2. **The runner and IR gained renderer-specific and motion-specific policy.** `crates/loft-runner/src/lib.rs:351` encodes Sun/Sky colors into a special slot. `crates/loft-ir/src/program.rs:132` adds a separate Motion descriptor, and `crates/loft-runner/src/motion.rs:26` hardcodes an `advance` pipeline, bindings and synchronous readback. Emission at `crates/loft-passes/src/lib.rs:796` visits drawn kinds only, so it can omit scheduled work on a table-only kind. Have lowering describe each scheduled dispatch with its entry, resources and requested outputs, independently of the draw list. Let the snapshot command request readback and the library provide lighting defaults. Preserve the unsupported-operation diagnostic for anything outside the row-local subset. Test a scheduled table-only row. The forbidden-word scan found 23 matching lines in Runner/IR, 21 inherited and two new `Pass::Shadow` matches at `crates/loft-ir/src/sexp.rs:48` and line 54. Validate generic pass resource references in one exhaustive dispatcher.

3. **A supported motion law can use native nondeterministic math.** `crates/loft-passes/src/emit.rs:477` rewrites only `sin`, `cos` and `atan2`. Classify reachable motion operations once, lower each wrapped operation through its fixed implementation, and refuse an unavailable implementation with E504 at the call. Inspect the emitted body for a direct call and one reached through a helper.

4. **Dimensionally invalid expressions type-check.** `crates/loft-parse/src/parser.rs:207` erases a declared unit to `f32` and line 1236 lowers the literal suffix. A sphere radius containing `1m + 1s` compiled. The phase consolidation acknowledges this deferral at `docs/spec/LOFT_V1_SYNTAX.md:127`. Preserve the dimension alongside the value through type checking, apply Addendum §11's arithmetic and promotion rules, and erase it at storage or emission. Verify E110 for length plus time and success for length plus millimetres.

5. **Heron's checks do not establish the claimed gaze and posture.** `agent_notes/2026-11-20_meta/v1_syntax/heron.loft:58` checks the yaw residual written by the gaze law itself. A reversed beak pitch leaves it green. 6. **Certification and cache dependencies are broader than the geometry.** `crates/loft-passes/src/lib.rs:120` gates exact SDF rules on one digest of the entire library file. Match each analytic certificate to the canonical body and its actual callees, and hash only tables reachable from that kind's geometry. Map Truth, parity, Load, usage, device and budget failures to Addendum §17 codes 2 through 7 respectively. Cover a missing frame and a missing input file through the actual CLI.

8. **Legal user names can collide with generated WGSL, and some suggested fixes use retired syntax.** `crates/loft-passes/src/emit.rs:86` checks keywords and a small list of internals.
