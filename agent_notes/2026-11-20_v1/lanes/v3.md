## Prediction before build

A single ordered pass list should submit 5/5 capsule, 5/5 blob and 17/17 hermit GPU commands at one and twenty objects. A wave joins adjacent commands targeting the same attachments or consecutive compute dispatches. Per-draw binding maps remain separate so the visibility and shadow bundles can reuse pipelines. Texture and grid initializers select the same compute and mip declarations at load or when watched parameter bits change. Path export should emit its ordinary storage tables and optional photon dispatch. Draw and dispatch order, index order, formats, and shader arithmetic should give exact RGBA on the 18 integrated frames. Expect the same five gate verdicts and a smaller functional L0 count. At least 2,496 lines of charged Std execution and policy sit outside this lane's ownership, so reaching 2,500 requires eliminating nearly all charged Runner and CLI source or changing those boundaries.

Bake and spectral hosting failed during bind-layout creation because its default device lacks write-only `R16Float` storage textures. The native device requests adapter-specific format features. Missing feature negotiation and the absence of a typed preflight refusal are both blockers for merging this branch.

The build succeeded on the third allowed attempt. The first compile exposed a result alias and a shadow-table type mismatch. The next exposed a missing `Stamps` import. The native workspace run reached 33 passes before fail-fast stopped on `profile_json_counts_executed_fixture`. The test replaces Classify's shader with an ABI-compatible shader whose buffer is named `data`. The new lowerer resolves it by WGSL symbol and rejects the name, exposing an archived IR compatibility regression. Bun passed 315/315. The domain-word scan passed.

The 116 tests that fail-fast had skipped ran from their existing lab executables, yielding 149/150 native passes overall. The capsules-1 Albedo, Depth, ID and Normal probes each matched the cut binary byte-for-byte at 1280×800. At pixel (640, 400) the archived beauty is RGBA (150, 152, 60, 255) and v3 saturates to (255, 255, 255, 255). This narrows the observed fault to the beauty-specific shaders or their bindings. Comparing the HDR values before presentation would distinguish these cases. The spectral study produced a native 128×128 image at four samples, with 10 load bake dispatches.
