## Source and measurements

- **Hermit.** `crates/loft-passes/src/emit/surface.rs` proves row and frame independence before emitting a cached grid entry. `crates/loft-cli/src/native/mod.rs` bakes the positions on the GPU and records the same original index winding for both cameras. The indexed and procedural controls agree at every pixel in beauty, depth AOV and ID on Hermit-20 at t = 0. These are image-space probes of projection and depth. Per-vertex clip coordinates and the raw depth attachment remain unmeasured. `emit/lighting.rs`, `lib/bsdf.loft` and `lib/light.loft` move the outgoing terms and fixed sky directions outside the 14-sample loop. The eight module hashes agree between counts 1 and 20. The extra load-only bake pipeline raises the Hermit pipeline total from 13 to 14. Official Hermit-20 p95 was **5.461 ms** against 5.1 predicted and 5.6 allowed. Vis, Shadow and Shade medians were **1.395/0.636/2.180 ms**. Whole-module Shell counts, including both vertex entries and the bake, were 694 ALU, 29 transcendentals and 45 storage loads.
- **Shrine.** `crates/loft-passes/src/paths/shadow.rs` combines the conservative BVH with exact caster queries from the authored shadow recipe. `crates/loft-cli/src/native/paths.rs` packs the caster rows and BVH. The renderer retains the Shadow pass boundary when the map draws are gone. All 3,072 instances remain in the program. The fixed close profile at t = 0 uses a radius of 6.4 m at 1280 × 800 with 30 warmups and 100 measured frames. The GPU bore fixture queried the two named Worlds and returned carved visibility 1 and solid visibility 0 on all 64 pixels. The per-hit schedule missed **19.437 ms** ring and **19.560 ms** immediate against 3.7 predicted and 4.0 allowed. The same-binary map control scored **4.210 ms**, with Shade median **0.532 ms** against **16.064 ms** with per-hit queries. Vis stayed near 2.24 ms and eliminating the map saved roughly 0.42 ms in Shadow. This isolates the regression to per-hit traversal during shading. Triangle controls were 0.046, 0.057 and 0.044 ms. Both query modes and the map control preserve their raw pass stamps.
- **Bake.** `crates/loft-passes/src/emit/column.rs` derives the X-only dependency of the InkMask sine and emits one value for each four-texel strip. `crates/loft-cli/src/native/mips.rs` reuses disjoint views, writes the original format at each level and keeps the original tap order. Native load took **3.733 ms** and **2.369 ms** against 1.8 predicted and 2.0 allowed. The repeat measured InkMask base and mips at 0.453 and 0.630 ms and cube base and mips at 0.021 and 0.547 ms. The interval from the end of mask mips to the start of the cube base was 0.716 ms on the repeat and 1.882 ms on the first run. Both totals include those intervals and the last mip. Load counted **20** dispatches. Frame totals were **8/3/3/8/3**, with three ordinary frame commands and **5/0/0/5/0** bake dispatches. Exact texel comparison against the unfused mip chain and vector parameter invalidation remain open.
- **Spectral.** `crates/loft-passes/src/world_path.wgsl`, `spectral_path.wgsl` and `crates/loft-cli/src/native/paths.rs` pack descriptors and media into checked ranges of the read-only world arena. The storage slots from Naga entry reflection in `crates/loft-passes/src/telemetry.rs` were 0 vertex, 7 fragment and 4 compute. The actual layouts account for both fixed group 0 storage buffers and use at most **8** fragment and **6** compute slots. On the eight-slot M4 the CLI loaded its real pipelines and rendered a 128² study at four samples. The closed furnace was 1.499512/1.749268/1.998413. White furnace was 0.499976/0.500063. The 1,000 lights averaged 545.625194 versus 546.25. Both joint-media orders returned L = (0.375, 0, 0.375) and T = 0.25. The GPU bore confirms World membership with the packed arena. The packed native shader loader requires rebuilding serialized path shaders that use the separate descriptor binding.

## Reproduction and residuals

- `CARGO_BUILD_JOBS=2 tools/dev.sh build loft-cli --bins --examples` finished on the final permitted retry. The first compile identified a missing module path attribute. The first retry found the edit bundle call signature and timestamp ring inference. Restoring the unchanged call signature and typing the ring let the next build finish. The built CLI is unchanged by the later removal of the CPU bore call from the Rust example. That example edit was left unbuilt under the retry cap. The archived CLI and GPU bore fixture execute the measured check.
- `tools/gpu_lock.sh out/meta/d1b/run.sh` ran the Hermit grid comparison before scene timings, the bake and light probes, spectral render, the six 300-frame A/B runs and `target/debug/loft profile --speed-gate`. The report `speed.json` is from the production Speed gate alone. i6 owns the combined full gate and suite.
- `tools/gpu_lock.sh out/meta/d1b/probes.sh` ran the 100-frame fixed Shrine profile, the 8² authored GPU bore, a bake repeat and the immediate-mode budget canary. The original Rust Shrine probe returned E405 on the analytic raw WGSL box in the CPU twin. The named-world build initially picked up the primary checkout's library because the fixture path was absolute. A copy inside the lane selected its own library and built four modules.
- `tools/gpu_lock.sh out/meta/d1b/shrine-discriminate.sh` repeated the per-hit Shrine in immediate mode. The archived map IR overflowed the debug decoder's stack. - `tools/gpu_lock.sh out/meta/d1b/pictures.sh` rendered all 18 layered cases and the six t = 0 shelf controls. `uv run --no-project --with pillow python out/meta/d1b/pixel-diff.py` checked the original manifest hashes and lossless pairs.

**ESCALATE.** Shrine's two timestamp modes agree on the Shade regression and the map control narrows its cost. The cheapest next check is a paired Shrine run that records node/leaf visits and compares the existing any-hit traversal against a directional traversal with inverse direction computed once and compact deferred siblings. Retain the bore result and the same cameras. The bake miss is concentrated in the measured gaps around its dispatches. The cheapest next check is an unfused GPU control with the same query placements, dumping every native-format mip of both textures. Keep the observed totals until both the time and texels are established.

**Dependencies.** Native `Loaded` still records its own frames. D1a's portable lowerer needs a `Compiled` value and refuses bake and path resources. Its public render recording method has no render timestamp or command-count input. To route the unchanged `Loaded` facade through it, the runner and lowering owners need to expose that plan, including the grid index, bake extent and format, and lifecycle clocks. The current parameter layout exposes scalar live words only. The vector slots must be reflected before dirty clocks can track every component. D1d published portable `mesh_intersect` after the last build. World assembly still carries only distance out of its intersection callback. The World consumer needs the selected triangle identity and matching geometry normal and material before it can dispatch this hook. The hardware Mesh World case remains unscored.
