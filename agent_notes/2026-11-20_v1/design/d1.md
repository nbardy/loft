## 3. Tier 0 edit overhead · d1c

**Cause.** The authored sphere changed radius from 0.59 to 0.64. Tier 0 took 3.125 ms p95, Tier 1 took 0.683, a **2.442 ms** difference. The 0.448 ms manual fixture runs one query per sample. The authored path splices a 28-case interpreter into `q_trace` for every march step, four normal taps and five AO taps. Even a sphere expands into length/normalize, splat and subtract. `TraceSession::edit` compiles the entire source, constructs the tape, regenerates WGSL for comparison and calculates changed buffers *before* starting its 0.064 ms clock. The CLI prints a literal zero for pipeline creations.

**Design.** Retain a checked graph per query with spans, dependencies, proved bounds and a stable layout. On source receipt, reparse and recheck the affected slice. A literal edit updates the pool and its dependent bounds. A structural edit re-emits the affected tape and bounds. A layout-changing edit gets an explicit reload outcome. Publish all writes as one generation before drawing. One lowering from the checked graph uses the ABI's 56 opcodes, including `SD_SPHERE`, with at most 32 live vec4 registers. Factor row/frame invariants out of position-dependent execution. For a primitive residual, select its frozen operation once outside the march and reuse the typed operands for the march and shade taps. General tapes retain a uniform instruction stream per dirty kind. Clean kinds stay specialized. Motion stays on its compiled path.

Start a monotonic CPU clock when edited source bytes arrive and stop after the final queue write. Report parse/check, bounds+tape, upload, total and actual pipeline-create calls. Specialize asynchronously after 400 ms quiet, on native and web. Install only the latest generation. Keep the original typed error/span when an edit cannot execute.

**Prediction and first check.** **1.2 ms** source→upload (cap 2), **0** foreground pipeline creations, **+0.35 ms** GPU p95 (cap 0.5), field error ≤1e−5 and ≥99.9% of shaded pixels within 1/255. First inspect the sphere's residual and invalidation set on CPU. Then use public `still --edit` at 1280×800 for the radius edit **and** a changed opcode graph. Compare against an independently compiled edited scene. Count the VM path taken, changed pixels, clean kinds touched and stale promotions installed. ## 4. Corpus, bead, retarget and hardware rays · d1d

**Certification.** The denominator is 295, the release threshold is 281 and **0** are certified. Only **187** candidates exist (3/39/75/70 by lane). Of these, 186 lack pinned R0g and the bead fails its nine frames. Even certifying all 187 leaves **94** more needed. All 187 met the sampled speed budget and repacked identically. The 51,234 rest samples cover 170 seeds and the compiler emitted zero authored checks. Fourteen previews omit source behavior. Seven animation keys and simplified water/materials leave cross-view and between-key behavior unproved.

Use one evidence row per frozen identity. Join source revision, views/times, candidate, pinned geometry/depth, source checks, speed, bundle roundtrip and a separate look decision. Recover missing ports, including each reusable module's original consumer where traceable. An identity without a drawable oracle stays unresolved. Derive missing observations from the independent pinned legacy source into scratch with provenance. Promoting any new reference belongs to its owner. **Only the intended beauty decisions** for 187 pairs in 17 batches await look approval. Approval alone adds **zero** technical certificates. The 18 Phase 4 layered comparisons have their own queue. [Corpus inventory](../../../out/meta/i5-r2/corpus-inventory.json) · [Owner queue](../../../out/meta/i5-r2/approval_needed.md)

**Bead.** A hit/sentinel and single center sample discard nearest-miss ink and sample coverage. Port the original query, four sample positions, ground depth and resolve order as a reusable authored observation. Compare one whole/through edge strip first, then all nine frozen RGBA frames. Predict **9/9**, from 5,344/4,720 depth misses at 512² and 8,080 at 1280×800 to ≤26/26/102 over one code, zero off-edge pixels and max cluster four. With current pins the immediate geometry ceiling is **1/295**. [Bead scores](../../../out/meta/i5-r2/bead.json)

**Retarget.** Static import already takes **23.854 ms/100k triangles**. The importer refuses multiple primitives, textures, skins and animation, then unconditionally returns E601 on retarget declarations. Lower primitives/materials, hierarchy/inverse binds and clip channels once at Stage 0 to shared assets, BODY rows and prior curves. Resolve names to joint indices, drive the target pose and measure a planted toe in world space over the whole contact. Predict **≤0.08 mm** (cap 0.1) and **<100 ms** static import. Use a valid two-rig planted walk and a missing-chain E601 control.

**Hardware rays.** The probe enables the feature with default device limits, then requests one BLAS geometry from a device permitting zero and panics. Compiled World queries never use the standalone helper. Negotiate feature **and** geometry/primitive/instance capacity at attach. Select native triangle traversal or portable BVH once, sharing hit/miss/unresolved semantics. First run the anchor hit at **1 m ±10 µm** and miss **−1** through a compiled World in both modes. Record which backend ran. i5 also lacks populated live slots, post-start/cross-device replay, Keel/browser frames and portable ASSETS payloads. Incompatible bundle layouts both declare ABI 1.
