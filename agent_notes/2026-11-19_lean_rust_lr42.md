## What

- **`loft-draw profile DIR`** (`rust/crates/loft-draw/src/profile.rs`). The timings that were `still --frames/--pose-time`
  move here, and `still` is one picture again. `profile` refuses `--out`; `still` refuses the timing flags.
  - Adds p95 to every quantile line and ends with one JSON line, `{"profile": {...}}`: loads, cpu/gpu quantiles, pose,
    cache bytes.
  - `--loads N` loads the scene N times on one device.
  - `--pipeline-cache DIR` routes the loads through loft-loader's Vulkan `PipelineCache`, then saves it. Every loft-draw
    device now asks for `PIPELINE_CACHE` where the adapter has it. On Metal the flag is refused as `environment`
    (exit 6) with the loader's message.
  - `--budget-ms MS`: a p95 GPU frame over MS gives the new `Verdict::Budget`, exit 7. Without timestamps it is an
    environment error.
- **Budget wiring** (§7: compile budgets in work units, so the refusal is deterministic):
  - `loft_ir::error::Limits([u64; 4])`, indexed by `Meter`, with `spend(meter, spent) -> Result<(), Error::Budget>`.
  - The addon's entry is now `run(job, limits: BigUint64Array)`, **abi 2**. `drive` charges `Meter::Nodes` after
    decode. `src/core/native.ts` gives `Native.run(job, limits: Limits)` and `UNLIMITED`. The wire's fixed
    `MAX_NODES` quota still applies on top.
- **`tools/parity/measure.ts`**: the §8.1 scorer. It does three alternating runs (owl, titan, heron, owl, …), each a
  fresh `nice 15` process. Per run it records:
  - getrusage CPU and peak RSS;
  - CPU per phase: start+library, link, design, TS compile, job write, crossing, wire decode;
  - the counts U, R and the live job;
  - load at start and end.

  Counts are checked first, against the model. Rust phases the driver does not run yet are priced at the model's
  rates *at the measured counts*, and the report says `scored: false`.
- **Linux runner**: `tools/parity/linux.sh MAC_R0_DIR` (the container or host entrypoint, which exits when done), plus
  two changes to `run.ts`:
  - `LOFT_PARITY_OUT` names the set;
  - `cross <R0 dir>` checks every native frame against the other set under `--rule cross`, and checks that every build
    ends the same way. Comparing zero frames is a fail.

  The script runs tape digest → corpus reference on Vulkan → cross against the Mac R0 → Titan cold/warm through the
  pipeline cache.
