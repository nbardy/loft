# Lane L6 (api-l6): one escape ladder, raw drawables and raw compute in `wgsl` text (18 Nov 2026)

Design: `docs/proposals/2026-11-18_authoring_api.md` section 4, work plan section 9 row L6. Branch `feat/api-l6`
(worktree `~/git/_wt/loft-api-l6`), from main `e7c3c5a` (L1 to L5 merged).

## What changed

- **`compute` takes a `wgsl` module.** `reads` and `values` are gone (each refused by name, with the fix): a hole is
  how a value enters, and a hole holding another pass's output is the dependency (`src/compute.ts`: a pass's reads
  are the outputs whose reading library functions its text calls). `entry` is inferred when the module has one
  `@compute` fn (for steps, one besides `when.start`). A build, load or steps pass whose text reads `time`, an input
  or a param is refused by name (only frame passes bind them); a hole reading a curve or table is refused.
- **Handles are functions.** `baked.sdf(uv)`, `sim.state(i, lane)` replace `.sample(uv)`, `fetch(handle, i, lane)` and
  `.wgsl`. In any text, `${sim.state}(f32(i), 0.0)` reads the same thing: in graph text it calls the function, in raw
  text it becomes a call of the output's reader library function with its time appended (`rawCall` in `src/expr.ts`,
  replacing `computeFetch`). Readers are bound under the output's symbol in passes too, as in drawables.
- **Entry points written once for any module** (`src/text/index.ts`): `rawOf`'s rewrite is now `scanRaw`, shared by
  raw functions (reads become added parameters, as L1 built) and `WgslState.entries(names)` (reads become accessor
  calls `loft_value_<k>()`; an entry point cannot take parameters). The module's compiler emits the accessors against
  its own bindings: `src/compile/compute.ts` over the pass's `inputs`/`params`, `src/draw/shader.ts` over the slots.
  Entry and module-scope texts are registered with `authored(...)`, so a typo is exit 4 at the author's line.
- **`draw.shader(name, wgsl\`...\`, { vertices, instances, phase, cull, depthWrite, blend })`** (`src/draw/shader.ts`,
  registered in `src/draw/index.ts`, `ShaderOptions` exported from `src/core.ts`). `sceneDepth` is inferred from a
  call of `scene_depth`/`scene_position`.
- **`camera_ray(px) -> Ray { o, d }`** (`src/text/raw_prelude.ts`): a library function raw text calls by name, emitted
  only into modules that call it, so no other artefact changes.
- **A typed `f32` module constant stays typed in raw text** (`f32(0.0166...)`): see "the check" below.
- Examples: `compute_frame.ts` (param and palette through holes, `time`), `compute_steps.ts` (two `draw.shader`
  drawables replace 30 lines of `Drawable` boilerplate; `const dt: f32` replaces `loft_dt`), `compute_volume.ts`
  (section 4's user code: the bake drawn by `draw.field` over a plane, `pbr`; exports `shape` and `baked`).
- Tests: `tests/shader.gpu.test.ts` (new, two checks below); `tests/compute.gpu.test.ts` migrated, same assertions.
- Docs: guide ("Your own shaders" replaces the hand-built `Drawable` snippet; "Writing a compute pass" rewritten),
  `docs/errors.md` (raw compute refusals), `DESIGN.md` 2.7 and 18, `docs/api.md` regenerated.

  writes: { state: { kind: "buffer", entries: 2048, lanes: 2 } }, dispatch: [32], wgsl: wgsl`... fn settle(...) {...}` });
const dust = draw.shader("dust", wgsl`
@vertex fn vs(@builtin(vertex_index) v: u32, @builtin(instance_index) i: u32) -> Grain {
  let p = ${sim.state}(f32(i), 0.0);
  ...`, { vertices: 6, instances: 2048, phase: "transparent", depthWrite: false, blend: "alpha", cull: "none" });

## The pass/fail check, measured

1. **Steps and frame examples byte-identical frames** (`loft render --views front --size 480x270`, rgba hash, before
   at `e7c3c5a` and after): `compute_steps` at 0.32, 1.2, 1.55 s: `e11386693db25399`, `1f0262261fc1109d`,
   `b324db96043ecf42`, all three equal. `compute_frame` at 0 and 0.7 s and at 0.7 s with `--param speed=3`:
   `2be5d20d8cf6b3f4`, `85e5da13f07a3870`, `2c30610b3efbf64d`, all equal. On the first run 1.2 s differed
   (`7c6a2c52...`) while 0.32 and 1.55 matched. Prediction before looking: `3.6 * dt` folded in abstract precision
   (an untyped literal) where `loft_dt` was an `f32` constant, a last-bit change compounded over 72 steps, invisible
   early and after the grains settle. Emitting a typed `f32` constant as `f32(...)` made all three equal.
2. **The ring renders through `draw.field`, depth-tested against a plane** (`tests/shader.gpu.test.ts`): the example's
   bake drawn green without ink, 160x100, with and without the plane; predicted per pixel by marching the source
   `shape.ring` on the CPU (a first hit below y = 0 is hidden, as the camera is above the plane). Pixels 2 or more from
   any change of class: **13,148 empty, 579 over the plane, 156 hidden; 0, 0, 0 differ.** This check found a bug in the
   design's code: the bake stored texel i at `i / 47 * 2 - 1` while `baked.sdf(uv)` reads texel i at `(i + 0.5) / 48`,
   a 2% scaling of the ring; the example stores texel centres.
3. **A raw drawable reading a param through a hole moves with it** (`tests/shader.gpu.test.ts`, centre pixel of a
   `draw.shader` returning `vec4f(${level}, 0.5 * time, -camera_ray(at.xy).d.z, 1.0)`): level 0.25 gives
   `[64, 128, 255, 255]`, level 0.75 gives `[191, 128, 255, 255]` (the time accessor and `camera_ray` exact too).
   Through the CLI, the guide's backdrop at `--param glow=0.6` and `0.1`: `485596aabe19dd4e`, `092b2f563adf5c86`.

Also: a typo in a `draw.shader` fragment and in a frame pass each exit 4 quoting the author's line
(`typo_shader.ts:8 ... unresolved value 'lvel'`); the six refusals (string, `reads`, `time` in build, a param in steps,
two entries, an uncalled handle) each name the fix. `pnpm typecheck` clean; `tests/{shader.gpu,compute.gpu,text,
text.gpu,show.gpu,identity}` 17/17; `tools/check_snippets.ts` 0 failed; `tools/check_loader_closure.ts` passes. Full
suite not run (per the brief). Stills: `2026-11-18_api_api-l6/ring_field.webp`, `dust_shader_1.2.webp`.

## Where I went off the design, and why

- `time` in raw text is the accessor of the `time` input (`inputs[k]`), not a rewrite to `frame.time.x`: one
  mechanism for every hole, and compute passes have no `frame`. Same value.
- Raw functions keep L1's added parameters; entry points use accessors. Both are one rewrite (`scanRaw`).
- `camera_ray` lives in `src/text/raw_prelude.ts`, not `src/compile/scene_wgsl.ts`: in the shared WGSL it would have
  changed every scene's artefact; as a library function it is emitted only where called.
- Raw code still cannot call a prelude function (`noise3`) directly; the refusal names the one-line wrap.

## What is left

- `src/host/host.ts` `refused`: the rule that a module labelled `compute "..."` is the scene's can go now that compute
  texts are registered (L4's file; one line).
- `draw.field` still requires `outline`, `schedule` and `paint`; section 4's example omits them (L5's option audit
  did not reach `draw.field`).
- A TextError's caret quote shows a hole as `loft_hole_0` (L1's quoting).
