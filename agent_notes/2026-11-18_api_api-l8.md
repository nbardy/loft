## Where I went off the design, and why

- **The budget grew 14%.** No numeric budget existed in code; the docs said "about 2,200" then "about 2,400", and
  main was already 2,495. A precise subset and prelude list cost ~300 words; the alternative (pointing at "WGSL's
  numeric builtins") would leave a model to guess which ones lower. The prelude names duplicate the API map's library
  lines, which carry the signatures; merging them needs an `api.ts` change (below).
- **Edited `docs/context.md`**, not in the row's file list: it is the written part `src/cli/context.ts` prints, so
  "context includes the subset" is a change there.
- **Exported `BUILTINS` from `src/text/lower.ts`** (L1's file, merged; one word) so the list is generated, not copied.
- WGSL keywords are unbackticked in `docs/context.md`: `check_snippets` requires every backticked identifier there to
  be a Loft export.
