## Decisions the plan left open (lanes 1.2, 1.3 and 2.x read these)

- **Wire.** Every span starts at a multiple of 8. Op codes are 0 Lit, 1 Leaf, 2 Call, 3 Fetch, 4 Loop, 5 Grad,
  6 Raw, 7 Swizzle and 16+i for `Prim::ALL[i]`; 8–15 are reserved. A decl is
  `[tag | arity<<8, name sym or u32::MAX, roots off, n]`. The `Fn`, `Loop`, `Param` and `Input` root layouts are
  in `graph::Decl`. Operands must precede their node, so the graph is a DAG by construction.
- **`Grad` takes no `wrt` field.** It is `args = [f, x]` with result `ty(x)`. Lane 1.3 may add one.
- **`Prim` lives in loft-ir.** It carries the name and the type rule. Lane 1.3's `PRIMS` in loft-core should index
  `Prim::ALL` in order and add the evaluation, interval and derivative rules.
- **Bundle fields the plan did not define** (Raster, Compose, Medium's light, TexFormat) are minimal placeholders.
  Lanes 3.1 and 3.2 reshape them freely, because no persisted consumer exists.
- **Decode cost.** 36–48 ns per node on the 1M chain, with the machine loaded. §8.1 budgets 35 ns per R for
  decode, intern and inline together. Lane 4.2 should profile this before Titan's numbers are trusted.

## Review (integrator pass, 19 Nov)

Re-run on M4, load 11-17: fuzz 90,513 refused / 9,487 well formed / 0 panics; bundle and identity tests green;
lint clean on both crates (`--all-targets -D warnings`); lane 0.1's `check_layers` and `check_test_layout`
(from `feat/lr01:tools/check.sh`) green; 1M-node crossing 1.9 ms Bun 1.3.10, 2.7 ms Node 22.22.1 (decode
36.5-38.7 ms, 37-39 ns/node). scc code: Rust 1,196 + TS 47 (src and build.rs), ceiling 1,700.

Fixed in review:
- **Cycles through decls.** Operands-before-users made node edges acyclic, but a `Call`/`Loop` names its decl by id,
  and a decl's roots could include the calling node (a Fn returning its own call, a Loop whose `next` is its own
  result). Inlining or unrolling would never end. Decode now refuses any Call/Loop whose decl has a root at or after
  it, as `Wire(Nodes, Order { root })`; with the existing rule the whole job is acyclic. The fuzz found 41 such
  mutants that the old decoder accepted. The recorder (lane 1.2) must record a body before the node that uses it.
- **Trailing bytes after a bundle's last section** are `Load(Trailing)`: otherwise one Bundle has two files and two
  `Identity::build` hashes.
- `tests/binding.ts` moved to `rust/crates/loft-node/binding_check.ts`: lane 0.1's test-layout gate refuses
  anything under `tests/` except `tests/it/`.
- `native()` resolves the lab addon with `fileURLToPath` (`URL.pathname` percent-encodes spaces).

Left (minor): a `Vec` whose parts sum past 4 components reports `got: Rec(sum)`, which is not a real type;
padding between bundle sections is not checked to be zero; `napi_create_function`/`napi_create_string_utf8`
statuses are ignored.
