# Cuts, 23 Nov 2026

Features removed from the v1 specification by the meta-engine review
(`agent_notes/2026-11-23_meta_engine/DESIGN.md` §7). Each row supersedes the spec text it names.

## Tier 0 tape VM (lane `cut-tape`)

| Removed | Spec text superseded | What replaces it |
|---|---|---|
| The Tier 0 GPU tape VM: the 56-opcode tape (`loft-abi::Tier0Opcode`), the `loft-tier0` crate, `Runner::register_tier0` / `hot_swap_tape`, the 400 ms quiet-period promotion to Tier 1, and the runner and native edit routes built for them | 00 decision 14; 02 §3 `hot_swap_tape` and §4 item 7; 06 §13 (the opcodes) | Recompiling the edited kind's module. `loft still SCENE OUT.png --edit EDITED --kind K` compiles the edited scene, refuses any change outside kind K, compiles K's render and shade pipelines and swaps them in with its rows and bounds, then checks the live picture against a fresh load. An edit is live in one pipeline-creation time (about 70–100 ms per pipeline) instead of under 2 ms. `Runner::hot_swap_module` is unchanged. The `.loftb` bundle format never carried tape words, so no wire layout changed. |

## Unused constructs (lane `cut-unused`)

The owner approved removing constructs with no use in `stdlib/` or `scenes/`
([design §7.2](../../agent_notes/2026-11-23_meta_engine/DESIGN.md)). This table takes precedence over
00–07, `PATCH_V1_2.md`, `06_ADDENDUM.md` and `LOFT_V1_SYNTAX.md` wherever they describe these constructs.
`loft.lark` already omits them.

| Removed | What a scene writes instead |
|---|---|
| `plan` (build-time trajectory solver), `sample_prior`, `PriorTable` | A kind whose rows hold the keys, read by a law (kinds with row references). |
| `solver … config { … }`, `constrain`, schedule verb `run_solver`, diagnostic `E503` | A kernel in a pass loop: an authored `pass` that dispatches the constraint kernel for each iteration. |
| `body` with `trunk`, `segment`, `chain`; `state … checkpoint N home …`; `retarget`, diagnostic `E601` | Kinds with row references: a parent kind (the trunk) and child kinds (legs, segments) that name their parent's row. Replay checkpoints are unchanged: the runner's checkpoint ring is set per bundle, not by `state`. |
| top-level `input` | `param` |
| statement `yield` | Return a value, or write a row field from a law. |
| `wgsl det (...)` | A Det law cannot reach a raw WGSL block (`E504`). Mark the law `nondet`, or write the operation in Loft. |
| schedule `waive Name "reason"` | Nothing. Waivers were never read. |
| kind query names `medium`, `sigma`, `tau` | Nothing. The parser accepts only `trace`, `material`, `visible` and `surface`. The World query `medium(p)` is unchanged. |
| Hardware ray query of static triangle meshes (BLAS builder, `mesh_ray_query`) | The software BVH. Native World traversal over instance AABBs still uses hardware ray query when the device grants it. |

Not removed, though listed with these in the design: schedule `if_some`/`if_true` (never implemented; no code or
grammar to delete) and `raster(` inside an authored pass (no implementation; it is the shape authored full-screen
raster passes will take).
