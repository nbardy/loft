# Retired Loft engine

On 19 November 2026, before Step 0, Loft removed the TypeScript engine, the first Rust workspace, and their build, test, viewer and migration tools from this tree. The full retired product is preserved at the Git tag `legacy/2026-11-19`.

The [legacy documentation](docs/legacy/) records how those engines worked. The [TypeScript examples](examples/) and [Creative seed pack references](docs/legacy/MIGRATION.md) are read-only source material for Phase 5 corpus regeneration.

The [v1.0 specification](docs/spec/) describes the Rust workspace in `crates/` and the `.loft` programs in `lib/` and `engines/`.
